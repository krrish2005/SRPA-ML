Optimization Objective Function & Heuristic

Multi-Objective Grid Search

The advisor searches interior coordinate candidates at discrete grid intervals. For each candidate coordinate \((x_c, y_c)\), it simulates the full ray-traced path loss across the floor plan and evaluates the multi-objective fitness score:

Score(x, y) = 1.0 × Good_Coverage_Percent - 2.5 × Dead_Zone_Percent + 0.1 × Average_RSSI_dBm

The heavy penalty (\(-2.5\times\)) against dead zones ensures the algorithm favors placements that penetrate dense barrier clusters (such as reinforced concrete master bedroom walls and kitchen tiling) while maintaining broad line-of-sight coverage for common areas.

Wireless RF Physics & Simulation Model

Scientific basis, empirical attenuation tables, and electromagnetic path-loss formulations.

1. Log-Distance Path Loss (LDPL) Model

IEEE Standard Formulation

In indoor environments, electromagnetic radio waves experience distance decay combined with shadowing and barrier absorption. The received signal strength indication (RSSI) at distance \(d\) from the transmitter is modeled as:

RSSI(d) = Ptx - [PL₀ + 10 · n · log₁₀(d / d₀)] - Σ Wall_Attenuation - Σ Obstacle_Attenuation
Ptx (Transmit Power): EIRP of access point in dBm. Default is 20 dBm (100 mW).
PL₀ (Reference Loss at 1m): Free-space path loss at d₀ = 1.0m. 40.0 dB for 2.4 GHz; 47.0 dB for 5.0 GHz.
n (Path Loss Exponent): Rate of signal decay. 2.0 = free space, 2.5 - 3.5 = residential indoor, 4.0+ = industrial.
Σ Wall & Barrier Losses: Accumulated transmission loss (dB) calculated via 2D ray-casting intersection with physical walls.

College Project & Research Disclaimer

This system calculates theoretical RF propagation using established empirical log-distance formulas and 2D ray-casting vector math. It simulates ideal dipole antenna radiation and does not account for multi-path Rayleigh/Rician fading, atmospheric humidity, or physical multipath beamforming reflection. It provides an engineering planning guideline for residential router installation.
